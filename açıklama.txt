 ilk olarak stack üzerinde işlem yapabilmek için temel operasyon fonksiyonlarını yazdık.
  bu fonksiyonlar doğrudan stack’in yapısını değiştiriyor.

operasyonları ve bu fonksiyonların üstüne exec fonksiyonlarını yazdık.
bu fonksiyonlar önce ilgili operasyonu çağırıyor, ardından yapılan işlemi ekrana yazdırıyor.

örnek akış:

1- <3 <3 <3 main başlar

int main(int ac,char **av)

input av : "3" "2" "5" "1"

2- <3 <3 <3 stack oluşturma

create_stack(ac,av) fonksiyonu

burada olanlar:

a) string int dönüşümü ft_atoi_safe
"3" ->> 3 olur  (tüm inputlar)
b)node oluşturma  (her sayı için)
new_node(3)
c)stack'e ekleme  add_back()

son durumda stack a :  top->3->2->5->1->null

3- <3 <3 <3kontroller

a) has_duplicate(A) aynı sayı var mı varsa exit
b) error_exit() yanlış input varsa program kapanır

4- <3 <3 <3  operasyonlar

başlangıç : a: 3→2→5→1 b:empty
sa(A)  A: 2 → 3 → 5 → 1
ra(A)  A: 3 → 5 → 1 → 2
pb(A → B) A: 5 → 1 → 2 B: 3

A STACK sorted:
1 → 2 → 3 → 5 B: NULL

INPUT
  ↓
main()
  ↓
create_stack()
  ↓
ft_atoi_safe()
  ↓
new_node()
  ↓
add_back()
  ↓
has_duplicate()
  ↓
STACK A oluşur
  ↓
SORT ALGORITHM
  ↓
exec_sa / ra / pb ...
  ↓
write("sa\n", "ra\n" ...)
  ↓
OUTPUT (instruction list)
